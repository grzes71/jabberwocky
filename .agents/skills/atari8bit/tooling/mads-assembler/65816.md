# 65816

## 13.10 65816 Addenda

MADS needs `OPT C+` for 65816 addressing modes. Mnemonics added to the 6502 set
(from `references/mnemonics.md` of the mads skill): `STZ SEP REP TRB TSB BRA COP MVN MVP PEA
PHB PHD PHK PHX PHY PLB PLD PLX PLY RTL STP TCD TCS TDC TSC TXY TYX WAI WDM XBA XCE
INA DEA BRL JSL JML`, plus `PER`.

| Mnemonic | Notes |
|----------|-------|
| `STZ dst` | store zero byte directly (replaces `LDA #0 / STA dst`) |
| `SEP #imm` / `REP #imm` | set / clear status-register bits; the `#` is mandatory |
| `BRL rel16` | 16-bit relative branch (±32 KB, cannot cross a bank) |
| `JSL addr24` / `JML addr24` | long subroutine call / long jump; long indirect uses `[]` |
| `MVN srcbk,dstbk` / `MVP srcbk,dstbk` | block move; source/destination bank operands, block length in `A`/`X`/`Y` |
| `PEA #imm` | push a 16-bit immediate (the `#` is mandatory) |
| `PER rel16` | push a PC-relative address (assembles as `62 lo hi`) |

Width handling (verified by assembling with MADS 2.1.6):

- `.A8` / `.A16` / `.I8` / `.I16` are the width directives: they emit `SEP #$20` / `REP #$20`
  (bytes `E2 20` / `C2 20`) respectively `SEP/REP #$10` (`.i16` = `C2 10`) and set the tracked width.
  `OPT C+` is required first, otherwise every 65816 mnemonic fails (*Undeclared macro STZ*).
- `.LONGA` / `.LONGI` (`ON|OFF`) are also valid MADS directives, but they only set the
  assembler's width assumption for M/X — they do **not** emit `SEP`/`REP`, unlike
  `.A8`/`.A16`/`.I8`/`.I16`. Use them after the mode was switched by other code.
- The width of an immediate otherwise follows the *value*: `lda #$12` → `A9 12`, `lda #$1234` →
  `A9 34 12`. Use the mnemonic suffixes to be explicit: `.b`/`.z` byte, `.w`/`.a`/`.q` word,
  `.l`/`.t` 24-bit (`lda.w $12` = `AD 12 00`).
- Operands below `$100` keep zero-page addressing regardless of the width setting
  (`lda $12` = `A5 12` under `.a8` and under `.a16`).
- `[]` selects long indirect addressing; prefix a `+` to keep brackets as an expression
  (`lda [2+4]` = long indirect `[6]`, `lda +[2+4]` = `lda 6`).

```asm
        opt   c+                 ; 65816 addressing modes
        .a16                     ; emits REP #$20 (tracked A = 16 bit)
        .i16                     ; emits REP #$10 (tracked X/Y = 16 bit)
        lda   #$1234             ; A9 34 12
        .a8                      ; SEP #$20, back to 8 bit
        .i8                      ; SEP #$10
        lda   #$12               ; A9 12
```
