# 65816

## 1.4  WDC 65C816 / 65C816

### Operating modes

```asm
        clc
        xce               ; C=0 -> native mode (E=0)
        ; ...
        sec
        xce               ; C=1 -> emulation mode (E=1)
```

After reset, the 65C816 always starts in **emulation mode** (`E=1`). Use `XCE`
to switch between emulation and native mode. In native mode, status bits 4 and
5 are `X` and `M`; in emulation mode the stacked status byte keeps the 6502
layout with the break-format bits set.

### New 65816-only opcodes

```
COP  #imm    — software interrupt with its own vector
BRL  rel16   — branch relative long
JSL  abs24   — long subroutine call; return with RTL
JML  abs24   — long jump (no return address pushed)
RTL         — return from JSL
PHD/PLD     — push/pull 16-bit direct-page register (D)
PHK       — push program bank register (PBR)
PHB/PLB   — push/pull data bank register (DBR)
PEA imm16 — push 16-bit immediate value
PEI (dp)  — push 16-bit indirect value from direct page
PER rel16 — push PC-relative address
REP #imm  — clear selected status bits
SEP #imm  — set selected status bits
MVN/ MVP  — block move
TCD/TDC   — transfer A <-> direct-page register
TCS/TSC   — transfer A <-> stack pointer
XBA/XCE   — swap accumulator bytes / exchange carry with emulation flag
```

### Size-prefixed mnemonics (65816, MADS / TASM syntax)

MADS only assembles 65816 instructions after `opt c+` (the default is the 8-bit
6502); `.A8`, `.A16`, `.I8`, `.I16` (and the combined `.AI8`/`.IA16` forms) then
declare the expected register widths.

```
LDA.b  #$80    ; 8-bit accumulator  (A8 / M=1)
LDA.w  label   ; 16-bit accumulator (A16 / M=0)
LDX.b  $80     ; 8-bit index        (I8 / X=1)
LDY.w  $1234   ; 16-bit index       (I16 / X=0)
```

MADS directives to set mode: `.A8`, `.A16`, `.I8`, `.I16`, `.AI8`, `.AI16`, `.IA8`, `.IA16`
(these emit `SEP`/`REP`), or `.LONGA ON|OFF` / `.LONGI ON|OFF`, which set only the
assembler's width assumption without emitting code. Both forms need `opt c+` first.

---

### 65C816 DLI-safe interrupt rules

* Set VDSLST **before** setting NMIEN bit 7 ($80) on XL/XE.
* 16-bit registers must be saved/restored if using native mode inside ISR.
* `RTI` restores `P` (including `M`/`X` in native mode). The `E` flag is changed
  only with `XCE`, not by `RTI`.
