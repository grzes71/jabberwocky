# Specification: MADS Memory Map Generator

## 1. Goal
Develop a Python CLI tool (`scripts/generate_memory_map.py`) that parses the symbol/listing output generated by the MADS 6502 assembler. The tool must analyze memory allocations, detect segment overlaps, and output a clear map of used blocks and free memory gaps to serve as the Single Source of Truth (SSOT) for the AI Agent and the build pipeline.

## 2. Inputs
- The tool must accept a file path to the MADS output via a command-line argument.
- MADS can generate a label file (`.lab`) via the `-l` flag or a symbol table. The parser must extract:
  - Label names.
  - Their resolved memory addresses (hexadecimal).
  - The start (`.org`) and estimated length of continuous data blocks (if inferable from consecutive addresses or listing output).

## 3. Outputs
The script must generate two files in the `docs/` directory:
1. **`docs/memory_map.json`**: A machine-readable format containing an array of segments (name, start_address, end_address, size, type).
2. **`docs/memory_map.txt`**: A human-readable visual summary formatted as an ASCII table showing:
   - Used memory segments (e.g., `$0800 - $09FF: DISPLAY_LIST`).
   - Explicitly calculated **FREE GAPS** (e.g., `[ FREE SPACE: $0A00 - $1FFF (5632 bytes) ]`).
   - A dedicated section for Zero Page usage (`$80 - $FF`).

## 4. Technical Requirements & Constraints
- **Python Modernity:** Use Python 3.10+. Utilize `dataclasses` (or `Pydantic` v2) to model memory segments.
- **CLI Design:** Use `argparse`. The script must support standard flags: `--input`, `--out-text`, `--out-json`.
- **Validation & Exit Codes:** 
  - The script must validate the memory model. If two data segments overlap, or if a user variable maps to the OS Zero Page (`$00 - $7F`), the script must print a clear error to `stderr` and exit with a non-zero status code (e.g., `sys.exit(1)`).
  - This ensures the `make` build pipeline breaks immediately upon memory corruption.
- **No External Dependencies (Optional but preferred):** Keep the script strictly dependent on the Python standard library unless `Pydantic` is already in `requirements.txt`.

## 5. Definition of Done
- The Python script correctly parses a sample MADS `.lab` file.
- It accurately calculates the gaps between `.org` blocks.
- It fails the build (exit code > 0) if a collision is artificially introduced.
- The instructions for integrating it into the `Makefile` (e.g., `python scripts/generate_memory_map.py --input build/main.lab ...`) are provided.
